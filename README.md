## 🛠️ Way of Work
Hinter den Kulissen setzen wir auf Qualität und ein strukturiertes Miteinander. Unser Workflow folgt klaren Spielregeln:  

### 🐙 Git-Workflow & Collaboration
Ein sauberes Repository ist unsere Basis. Wir arbeiten nach diesen Prinzipien:
* **Branch-per-Feature:** Entwicklung findet ausschließlich auf Feature-Branches statt (z. B. rules-screen). Der main-Branch bleibt stabil und unberührt. 
* **Protected Main:** Direkte Commits auf main sind technisch unterbunden. Qualität geht vor Schnelligkeit. 
* **No-Force Policy:** Wir achten die Arbeit der anderen. force-pushes auf Shared Branches sind tabu, um die Commit-Historie konsistent zu halten. 
* **PR or it didn't happen:** Änderungen fließen nur über Pull Requests ein. Jede Zeile Code wird durch ein Peer-Review geprüft, bevor sie gemerged wird.
